# Afterclass Frontend

Frontend de Afterclass hecho con React + Vite + Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

Corre en `http://localhost:5173` y hace proxy de `/category` y `/post` al backend en `http://localhost:8000`.

## Cómo contribuir

Revisa `docs/CONTRIBUTING.md` en la raíz del repositorio. Resumen:

1. Crea una rama desde `main`.
2. Haz tus cambios.
3. Verifica que compile: `npm run build`.
4. Commit con mensaje claro y abre un Pull Request.
